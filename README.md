# Movie Ticket Booking System

This is a simple **Movie Ticket Booking System** developed using **C++**.

The project is a console-based application that helps manage movie ticket bookings and seats.

## Features

- Display movie details and seat layout
- Book movie tickets
- Check available and booked seats
- Cancel bookings
- Search bookings by customer name
- Change the booked seat
- Calculate ticket price with GST
- Display occupancy and revenue reports
- Validate customer and booking details
- Prevent booking of already occupied seats

## C++ Concepts Used

- Structures
- Arrays
- 2D Arrays
- Strings
- Functions
- Searching
- Conditional statements
- Loops
- Input validation
- Time and space complexity

## Project Details

The system contains **80 seats** arranged in **8 rows and 10 columns**. Different rows have different ticket prices such as Standard, Premium, and Recliner.

The project is designed to demonstrate how basic **C++ and Data Structures concepts** can be used to build a real-world application.

## How to Run

Compile the program using:

```bash
g++ main.cpp -o main
```

Then run:

```bash
./main
```

On Windows:

```bash
main.exe
```
